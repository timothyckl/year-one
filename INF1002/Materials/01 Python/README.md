(weeks 1-7, the "1st half" of the module).

## Assessment context

The Python half is assessed by:

| Item | Weight | Notes |
|------|--------|-------|
| Python Quiz | 20% | Week 6, close book, online MCQ, tests understanding of labs/lectures |
| Python Lab | 5% | Autograded via Gradescope, 3 questions per lab |
| Python Group Project | 25% | 5 people, submitted around week 6 |

C (2nd half) is separate and organised under `../02 C`.

## Suggested reading order

1. Lecture notes in order (0 -> 5).
2. For each lecture, do the matching lab README:
   - Lab1 follows Lecture 1-2 (basics, I/O, formatting).
   - Lab2 follows Lecture 2-3 (loops, data structures, file I/O).
   - Lab3 follows Lecture 4 (functions, modules, higher-order).
   - Lab4 follows Lecture 5 (recursion, docstrings).
   - Lab5 follows Lecture 4-5 (higher-order functions, lambda).
3. Before the quiz: skim `03 Revision Notes`, then drill the `04 Reference Guides`.
