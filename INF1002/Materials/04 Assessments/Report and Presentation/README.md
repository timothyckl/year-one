# Report and Presentation - Assessment

## Quick summary
Checklist and guidance for the written report, demo video/presentation, and
GitHub deliverables, covering page limits, a recommended structure, and
guidance drawn from previous submissions.

## Files
- [`Report and Presentation Overview and Checklist.md`](Report%20and%20Presentation%20Overview%20and%20Checklist.md) - full checklist
  separating explicit requirements from recommendations.

## Historical key numbers
- Report length: 10-15 pages, single column, font size 11+, standard margins;
  excludes title page, TOC, appendix; report must be self-contained.
- Report length (C project): no more than 15 pages, Times New Roman,
  font size 11+.
- Video: total 15 minutes (presentation max 5 min + demo max 10 min).
- Video (Python context): must be no longer than 10 minutes; extensions
  require lab supervisor approval.
