# INF1002 Programming Fundamentals

INF1002 introduces programming through Python and C. The module begins with
high-level problem solving and Python data structures, then moves into C to
develop a more explicit understanding of compilation, memory, pointers, linked
structures, and file operations.

These materials cover the AY25/26 run of the module. Assessment formats and
schedules may differ in another run.

## Learning Focus

By working through the module material, students develop the ability to:

- translate a problem into logical steps and implement those steps as a program;
- use variables, expressions, control flow, functions, and modular design;
- choose and work with strings, lists, tuples, dictionaries, arrays, and linked
  structures;
- apply recursion and higher-order functions where they suit the problem;
- understand C addresses, pointers, dynamic memory, and explicit file handling;
- test, debug, explain, and improve program behaviour;
- produce maintainable code and communicate technical decisions in a team; and
- evaluate AI-generated assistance rather than treating it as automatically
  correct.

## Practical Work

Friday labs contain ungraded warm-up work and three graded questions, with
submissions autograded through Gradescope. The lab notes explain the tasks,
expected behaviour, execution steps, and known defects.

Group projects develop problem abstraction, modular implementation, testing,
project management, communication, and technical reporting. The Python project
sequence progresses from proposal and system design through development,
testing, documentation, and demonstration.

## Responsible Use Of AI

The module treats AI programming tools as aids for planning, explanation,
implementation, debugging, and review. Their output still requires technical
understanding and evaluation. The introductory material explicitly warns against
submitting generated code or reports without ownership and against copying work.
Current institutional rules and assignment declarations always take precedence.
