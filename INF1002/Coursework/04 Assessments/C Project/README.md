# C Project - Assessment

## Quick summary
Team project to build a Class Management System (CMS), a simple command-line
database management system in C. A single data table ("StudentRecords") is
stored in a text file; the program supports OPEN, SHOW ALL, INSERT, QUERY,
UPDATE, DELETE, and SAVE, plus enhancement features (sorting, summary
statistics, a unique feature). Assessed via code (80%), report (10%),
individual reflection (5%), and video presentation/demonstration (5%).
