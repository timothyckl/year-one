# Python Project - Assessment

## Quick summary
Team project to abstract a real-world problem into logical structures and
implement it in Python, emphasising modular, efficient, maintainable code,
appropriate use of libraries, and teamwork. Assessed via a written report,
a demo video, and GitHub. Three project topics were offered (Stock Market
Trend Analysis, Sentiment Analysis System, Phishing Email Detection).

## Key numbers (historical)
