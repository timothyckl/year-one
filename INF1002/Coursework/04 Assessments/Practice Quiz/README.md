# Practice Quiz - Assessment

## Quick summary
A topic-oriented revision guide and question index for the 37-question
Python Trial Questions. The trial quiz itself does not include an answer key,
so this folder deliberately provides study guidance and self-check pointers -
NOT fabricated official answers.

## Files
- [`Python Trial Quiz Revision Guide.md`](Python%20Trial%20Quiz%20Revision%20Guide.md) - topics, what each question tests,
  revision pointers, pitfalls, and a full question-to-topic index.
