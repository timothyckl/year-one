# Lecture 0 - Module Introduction

## Purpose of this lecture

Sets expectations for the whole module (Python in weeks 1-7, C in weeks 8-13),
explains how the course is assessed, how labs and the group project work, and
gives guidance on using AI tools (ChatGPT) responsibly.

## Labs

- Groups and instructors are found on xSiTe (Class Activities -> Classlist ->
  View By Sections). Labs run on Fridays.
- Each lab has:
  - Warm-up questions (not submitted),
  - Three graded questions per lab, autograded on Gradescope.
- Optional, ungraded LeetCode-style problems for interview practice
  (arrays, strings, linked lists, trees, binary search, dynamic programming).

## Group project

- 5 people per group, groups randomly assigned on xSiTe.
- Example ideas: Stock Market Analysis; "Best Time to Buy and Sell Stock".
- Goals: abstract real-world problems into logical structures and implement
  them; write modular, efficient, maintainable programs; practise project
  management, communication, conflict resolution.
- Deliverables timeline:
  - Week 1: Proposal (team list, title, short description, initial task allocation).
  - Week 2: System Design (breakdown, core features, dataset description).
  - Weeks 3-4: Development (core code, working prototype, GitHub link).
  - Weeks 5-6: Testing & Final Report (testing report, docs, demo video).

## Using ChatGPT / "vibe coding"

- "You must be proficient in using AI programming tools, but you should still
  have a solid understanding of programming fundamentals".
- Vibe coding (Karpathy): developer describes the task, LLM generates code,
  developer reviews and requests improvements; minimal micromanaging.
- Skills needed to use it well: know the target clearly, allocate
  tasks effectively, estimate difficulty/time, evaluate output, give specific
  actionable feedback; "We are not born to be a boss - we need to learn."
- Suggested usage phases:
  - Forethought: brainstorming, outlining datasets/toolchains, workflow diagrams.
  - Performance: generating code templates, debugging, hyper-parameter tuning,
    asking for concept/library explanations.
  - Self-Reflection: benchmarking, technical writing, reviewing what worked.
- Warnings: "ChatGPT does not have a soul, you should have one";
  use AI as a learning aid, not a shortcut; maintain original thinking; AI makes
  a lot of mistakes.
- Classroom expectations: copying another student's work (or letting
  someone copy yours) is a disciplinary offence; don't submit AI-generated code/
  reports as your own; "Do not lie to yourself."
