# Year One Coursework Archive

Freshman coursework, projects, assignments, and notes archived in a single repository.

## Repository Structure

Each module uses a root `README.md` for its overall module information. Where
applicable, module content is organised into:

- `Materials/` for lectures, revision notes, reference guides, and assessments;
- `Notes/` for personal notes and rendered documents;
- `Projects/` for assignments and project source files.

Folder availability varies according to the content retained for each module.
