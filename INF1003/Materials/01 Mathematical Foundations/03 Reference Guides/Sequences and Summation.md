# Sequences and Summation Reference

## Sequence Formulas

| Type | n-th term | Sum of n terms |
|---|---|---|
| AP | $a_n = a + (n-1)d$ | $S_n = \frac{n}{2}(2a + (n-1)d)$ |
| GP | $a_n = ar^{n-1}$ | $S_n = \frac{a(1-r^n)}{1-r}$, $r \ne 1$ |
| Infinite GP | | $S_{\infty} = \frac{a}{1-r}$, $|r| < 1$ |

## Standard Sums

| Sum | Result |
|---|---|
| $\sum_{k=1}^{n} k$ | $\frac{n(n+1)}{2}$ |
| $\sum_{k=1}^{n} k^2$ | $\frac{n(n+1)(2n+1)}{6}$ |
| $\sum_{k=0}^{n} ar^k$ | $\frac{a(r^{n+1} - 1)}{r - 1}$, $r \ne 1$ |

## Summation Properties

- $\sum c a_k = c \sum a_k$
- $\sum (a_k + b_k) = \sum a_k + \sum b_k$

## Compound Interest

- Annual: $A = P(1 + r)^n$

## Product Notation

- $\prod_{k=1}^{n} k = n!$
