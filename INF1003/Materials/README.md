# INF1003 Materials

This directory contains the study and assessment materials for INF1003.
Personal tutorial notes are maintained separately in [`../Notes/`](../Notes/README.md).

## Directory Structure

| Directory | Contents |
|---|---|
| [`01 Mathematical Foundations/`](01%20Mathematical%20Foundations/README.md) | Topics 1--3: sequences and summation, number theory, and combinatorics. Contains `01 Lectures/`, `02 Revision Notes/`, and `03 Reference Guides/`. |
| [`02 Logic and Proof/`](02%20Logic%20and%20Proof/README.md) | Topics 4--7: propositional logic, predicate logic, rules of inference, and proof methods. Contains `01 Lectures/`, `02 Revision Notes/`, and `03 Reference Guides/`. |
| [`03 Sets Functions and Relations/`](03%20Sets%20Functions%20and%20Relations/README.md) | Topics 8--10: set theory, functions, and relations. Contains `01 Lectures/`, `02 Revision Notes/`, and `03 Reference Guides/`. |
| [`04 Assessments/`](04%20Assessments/README.md) | Quiz preparation, final-examination revision, assessment checklists, and submission guidance. |
| `Archive/` | Local audit-only copies of official module, lecture, tutorial, practice, and reference source materials. |

Use the numbered topic directories for study notes and reference guides, and
use `04 Assessments/` for quiz and examination preparation.
