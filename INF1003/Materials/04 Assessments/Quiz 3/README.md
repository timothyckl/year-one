## Key Revision Areas

### Proof Methods
- Choose the right proof strategy: direct, contrapositive, contradiction, cases
- Direct proof: assume $p$, derive $q$
- Contrapositive: prove $\neg q \to \neg p$
- Contradiction: assume $\neg p$, derive a contradiction
- Counterexample: one example disproves a universal claim
- Prove both directions of an "iff" statement
- Existence proof (constructive) and uniqueness proof structure
- Avoid circular reasoning and affirming the consequent

### Set Theory
- Define sets by roster and set-builder notation
- Compute union, intersection, difference, and complement
- Determine subset relations and set equality
- Prove set identities using element arguments or membership tables
- Compute power sets: $|P(A)| = 2^{|A|}$
- Compute Cartesian products: $|A \times B| = |A| \cdot |B|$
- Know all set identities (De Morgan, distributive, etc.)

### Functions
- Determine if a rule is a valid function (each domain element maps to exactly one value)
- Identify domain, codomain, and range
- Prove injectivity: $f(x) = f(y) \Rightarrow x = y$
- Prove surjectivity: for all $y$, exists $x$ with $f(x) = y$
- Prove or disprove bijectivity
- Compute sums and products of functions
- Compute composition $(g \circ f)(x) = g(f(x))$
- Find inverse functions for bijective $f$
- Apply floor and ceiling functions
