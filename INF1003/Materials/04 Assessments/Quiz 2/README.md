## Key Revision Areas

### Propositional Logic
- Translate English sentences into propositional logic
- Construct and interpret truth tables ($2^n$ rows for $n$ variables)
- Apply De Morgan's laws and other logical equivalences
- Determine if a compound proposition is a tautology, contradiction, or contingency
- Determine whether a compound proposition is satisfiable
- Know connective precedence: $\neg > \land > \lor > \to > \leftrightarrow$

### Predicate Logic
- Determine truth value of $\forall x P(x)$ and $\exists x P(x)$ over given domains
- Negate quantified expressions correctly (flip $\forall \leftrightarrow \exists$)
- Translate English into predicate logic:
  - "All P are Q" $\to$ $\forall x (P(x) \to Q(x))$
  - "Some P are Q" $\to$ $\exists x (P(x) \land Q(x))$
- Understand nested quantifiers: order matters for mixed types
- Distinguish bound from free variables

### Rules of Inference
- Identify valid argument forms (modus ponens, modus tollens, etc.)
- Detect fallacies (affirming the consequent, denying the antecedent)
- Know all 8 propositional rules by name and form
- Apply predicate logic rules: UI, UG, EI, EG
- Construct step-by-step proofs citing rules and line numbers
