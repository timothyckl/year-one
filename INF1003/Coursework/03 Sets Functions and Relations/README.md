# Sets, Functions, and Relations

Topics 8--10 of INF1003 cover the core discrete structures: set theory,
functions, and relations. Quiz 3 covers Topics 7--9 (Week 12, 15%), including
Topics 8--9 from this section.

## Topics

| Topic | Title | Key concepts |
|---|---|---|
| 8 | Set Theory | Set definition, set operations, subsets, set identities, cardinality, power sets, Cartesian products |
| 9 | Functions | Definitions, injective/surjective/bijective, composition, inverse functions, function proofs |
| 10 | Relations | Definitions, properties (reflexive, symmetric, antisymmetric, transitive), equivalence relations |
