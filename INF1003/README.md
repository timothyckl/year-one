# INF1003: Discrete Mathematics

Archived coursework for INF1003.

## Repository Structure

- [`Notes/`](Notes/README.md) is the main tutorial collection. It contains
  the editable LaTeX sources in [`Notes/tex/`](Notes/tex/) and the rendered
  documents in [`Notes/pdf/`](Notes/pdf/) for Tutorials 1--10.
- [`Materials/`](Materials/README.md) contains lecture notes, revision notes,
  reference guides, assessment preparation, and audit-only source materials.

Personal tutorial documents are maintained only in `Notes/`; `Materials/` does
not contain a separate set of tutorial guides.
